# Отчёт по лабораторной работе 1

## Анализ продаж

**Дисциплина:** Функциональное программирование  
**Язык программирования:** Python  
**Файл программы:** sales_analysis.py

## Цель работы

Разработать чистые функции для разбора таблицы продаж, вычисления общей
выручки и поиска строки с максимальной выручкой. Закрепить использование
lambda-функций и функций высшего порядка map, filter и max.

## Постановка задачи

Требуется реализовать три функции:

1. **fedos_mak_parse_csv(data)** принимает таблицу в виде CSV-строки и
   возвращает список словарей. Ключами служат названия колонок, значениями —
   строковые поля соответствующей записи.
2. **fedos_mak_compute_revenue(rows)** принимает список словарей и возвращает
   сумму произведений quantity × price.
3. **fedos_mak_top_item(rows)** возвращает копию строки с максимальным
   произведением quantity × price. Для пустого списка результат равен None.

Имена содержат уникальный префикс **fedos_mak_**. Поэтому при объединении работ
нескольких студентов определения с обычными именами не переопределят функции
этой работы.

## Область определения

Вместо перечисления всех возможных неправильных входов задаётся допустимое
множество данных.

Для **fedos_mak_parse_csv** допустимым входом является строка учебного CSV:
первая непустая строка содержит названия колонок, следующие непустые строки
содержат соответствующие значения, разделённые запятыми.

Для **fedos_mak_compute_revenue** и **fedos_mak_top_item** допустимым входом
является список словарей, в каждом из которых присутствуют ключи quantity и
price. Их значения записываются как числовые строки, распознаваемые функцией
float. Например, число два вводится как **2**, а не как **два**. Словесная
запись числа не принадлежит области определения функций.

При таком определении области все три функции тотальны: для каждого допустимого
аргумента существует результат.

Множества входных и выходных значений:

- **fedos_mak_parse_csv:** строка → список словарей со строковыми значениями;
- **fedos_mak_compute_revenue:** список допустимых словарей → вещественное число;
- **fedos_mak_top_item:** список допустимых словарей → словарь или None.

## Теоретические сведения

Чистая функция обладает следующими свойствами:

1. Детерминированность. Одинаковые аргументы всегда дают одинаковый результат.
2. Тотальность. Функция определена для всех значений своей области определения.
3. Отсутствие побочных эффектов. Функция не взаимодействует с внешним миром
   и не изменяет переданные данные.

Условное выражение само по себе не является побочным эффектом. В функции
разбора оно возвращает пустой список для пустого CSV и не изменяет внешнее
состояние.

Функция высшего порядка принимает другую функцию как аргумент или возвращает
функцию. В решении используются стандартные функции высшего порядка:

- filter оставляет только непустые строки;
- map преобразует строки и значения;
- max принимает функцию ключа и выбирает строку с наибольшей выручкой;
- lambda задаёт передаваемые операции без создания отдельных функций
  через def.

## Листинг программы

    fedos_mak_parse_csv = lambda data: (
        lambda lines: (
            []
            if not lines
            else (
                lambda headers: list(
                    map(
                        lambda line: dict(
                            zip(
                                headers,
                                map(
                                    lambda value: value.strip(),
                                    line.split(","),
                                ),
                            )
                        ),
                        lines[1:],
                    )
                )
            )(
                list(
                    map(
                        lambda value: value.strip(),
                        lines[0].split(","),
                    )
                )
            )
        )
    )(
        list(
            filter(
                lambda line: line.strip() != "",
                data.splitlines(),
            )
        )
    )

    fedos_mak_compute_revenue = lambda rows: sum(
        map(
            lambda row: float(row["quantity"]) * float(row["price"]),
            rows,
        ),
        0.0,
    )

    fedos_mak_top_item = lambda rows: (
        None
        if not rows
        else dict(
            max(
                rows,
                key=lambda row: (
                    float(row["quantity"]) * float(row["price"])
                ),
            )
        )
    )

## Алгоритм разбора CSV

Метод splitlines получает последовательность строк. filter удаляет пустые
строки. Из первой оставшейся строки формируется список заголовков. Затем map
обрабатывает каждую строку данных: разделяет её по запятым, удаляет внешние
пробелы и объединяет значения с заголовками при помощи zip. Конструктор dict
создаёт итоговый словарь.

Если после фильтрации строк не осталось, условное выражение возвращает пустой
список.

## Алгоритм вычисления выручки

map сопоставляет каждой строке продаж произведение
float(row["quantity"]) × float(row["price"]). Функция sum складывает
полученные значения. Начальное значение 0.0 обеспечивает вещественный
результат и корректный ответ для пустого списка.

## Алгоритм поиска строки с максимальной выручкой

Функция max сравнивает строки по ключу, заданному через lambda. Ключом является
произведение quantity × price. Если список пуст, условное выражение возвращает
None. Для непустого списка создаётся копия найденного словаря при помощи dict,
поэтому через результат нельзя изменить исходную строку. Если несколько строк
имеют одинаковую максимальную выручку, возвращается первая из них.

## Проверка чистоты

| Критерий | Выполнение |
|---|---|
| Детерминированность | Результаты зависят только от аргументов |
| Тотальность | Выполняется на описанной области определения |
| Ввод и вывод | Отсутствуют |
| Импорт модулей | Отсутствует |
| Глобальное изменяемое состояние | Не используется |
| Мутация аргументов | Отсутствует |
| Исключения | Не возникают для допустимых входов |
| Промежуточные присваивания | Внутри вычислений отсутствуют |

Три присваивания верхнего уровня связывают lambda-функции с уникальными
именами. Эти связи необходимы, чтобы преподаватель мог вызвать функции.
После создания функции не изменяют данные, связанные с именами.

## Рефлексия по уровню 4

### Есть ли в функциях побочные эффекты

Нет. Функции не выполняют ввод или вывод, не импортируют модули, не читают
внешнее состояние и не изменяют переданные строки, списки или словари.

### Что произойдёт при наличии пустой строки

Пустая строка внутри CSV будет удалена функцией filter и не попадёт в
результат. Если весь CSV пуст, **fedos_mak_parse_csv** вернёт пустой список.
Для пустого списка **fedos_mak_compute_revenue** вернёт 0.0, а
**fedos_mak_top_item** вернёт None.

### Какие множества значений принимаются и возвращаются

**fedos_mak_parse_csv** отображает множество допустимых CSV-строк во множество
списков словарей со строковыми ключами и значениями.

**fedos_mak_compute_revenue** отображает множество допустимых списков строк
продаж во множество вещественных чисел.

**fedos_mak_top_item** отображает множество допустимых списков строк продаж
во множество словарей, дополненное значением None для пустого списка.

## Контрольные примеры

Исходная строка:

    item,quantity,price
    Tea,2,150.5
    Coffee,3,200

Результат разбора:

    [
        {"item": "Tea", "quantity": "2", "price": "150.5"},
        {"item": "Coffee", "quantity": "3", "price": "200"},
    ]

Расчёт выручки:

    2 × 150.5 + 3 × 200 = 901.0

Строка с максимальной выручкой:

    {"item": "Coffee", "quantity": "3", "price": "200"}

| Проверка | Ожидаемый результат |
|---|---|
| Разбор приведённого CSV | Список из двух словарей |
| Общая выручка | 901.0 |
| Строка с максимальной выручкой | Словарь Coffee |
| Разбор пустой строки | Пустой список |
| Выручка пустого списка | 0.0 |
| Лучший элемент пустого списка | None |
| Повторный вызов с теми же данными | Тот же результат |
| Состояние входного списка после всех функций | Не изменяется |

## Вопросы для защиты

### Почему функции считаются чистыми

Все три функции зависят только от аргументов, не выполняют ввод или вывод, не используют
изменяемое глобальное состояние и не изменяют аргументы.

### Почему запись два недопустима

Поле входит в область определения вычислительной функции только тогда, когда
оно содержит числовую строку, которую преобразует float. Запись **2**
является числовой, а **два** — нет.

### Почему ошибка на слове два не нарушает тотальность

Тотальность проверяется относительно области определения. Словесные записи
чисел в неё не входят. Для каждого допустимого списка строк функция возвращает
число.

### Зачем используются lambda-функции

Они позволяют передать операцию непосредственно в map или filter и не
создавать отдельные именованные функции и промежуточные переменные.

### Почему map и filter являются функциями высшего порядка

Они принимают функции в качестве аргументов: filter получает предикат,
а map — правило преобразования.

### Можно ли использовать условное выражение

Да. Условие не создаёт побочного эффекта. Здесь оно только выбирает результат
для пустой и непустой последовательности строк.

### Как устранён конфликт имён

Все три функции имеют префикс **fedos_mak_**. Их имена не совпадают с обычными
именами функций из работ одногруппников.

### Какова вычислительная сложность

Все три функции проходят входные данные один раз. Временная сложность линейная:
O(n), где n — размер CSV или число строк продаж.

## Вывод

В работе реализованы три чистые lambda-функции. Первая преобразует допустимую
CSV-строку в список словарей, вторая вычисляет общую выручку, третья возвращает
копию строки с максимальной выручкой. Решение не использует импорт модулей,
ввод-вывод, мутацию аргументов и промежуточные присваивания. Применены функции
высшего порядка map, filter и max.
