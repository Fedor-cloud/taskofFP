# Отчёт по лабораторной работе 2

## Анализ частоты слов

**Дисциплина:** Функциональное программирование  
**Язык программирования:** Python  
**Файл программы:** text_analysis.py

## Цель работы

Разработать чистые функции для разбиения текста на слова, подсчёта частоты слов
и поиска самого частого слова. Закрепить использование lambda-функций и
функций высшего порядка map и min.

## Постановка задачи

Требуется реализовать три функции:

1. **fedos_mak_split_words(text)** приводит текст к нижнему регистру, удаляет
   влияние знаков препинания и возвращает список слов.
2. **fedos_mak_count_word_frequencies(words)** возвращает словарь
   «слово → количество вхождений», не изменяя исходный список.
3. **fedos_mak_top_word(freq)** возвращает самое частое слово. Для пустого
   словаря результат равен None.

Имена содержат уникальный префикс **fedos_mak_**. Поэтому при объединении работ
нескольких студентов функции не будут переопределены обычными именами из
чужого решения.

## Область определения

Вместо перечисления всех неправильных вариантов задаются множества допустимых
входных значений.

Для **fedos_mak_split_words** допустимым входом является любая строка.

Для **fedos_mak_count_word_frequencies** допустимым входом является список
строк. Каждая строка рассматривается как одно слово.

Для **fedos_mak_top_word** допустимым входом является словарь, ключами которого
служат строки, а значениями — неотрицательные целые количества вхождений.

При равной максимальной частоте функция **fedos_mak_top_word** выбирает слово,
которое раньше идёт по алфавиту. Это правило делает результат однозначным и
детерминированным.

Множества входных и выходных значений:

- **fedos_mak_split_words:** строка → список строк;
- **fedos_mak_count_word_frequencies:** список строк → словарь строк и целых
  неотрицательных чисел;
- **fedos_mak_top_word:** словарь строк и целых неотрицательных чисел →
  строка или None.

## Теоретические сведения

Чистая функция обладает следующими свойствами:

1. Детерминированность. Одинаковые аргументы всегда дают одинаковый результат.
2. Тотальность. Функция определена для всех значений своей области определения.
3. Отсутствие побочных эффектов. Функция не взаимодействует с внешним миром
   и не изменяет переданные данные.

Lambda-функция задаёт короткое преобразование без отдельного определения
через def. Функция высшего порядка принимает другую функцию как аргумент или
возвращает функцию.

В решении используются:

- def и аннотации типов для правильной записи публичных функций;
- map для построения пар «слово, количество»;
- min с параметром key для выбора самого частого слова;
- lambda-функции для передачи операций в функции высшего порядка без
  промежуточных присваиваний.

## Листинг программы

    def fedos_mak_split_words(text: str) -> list[str]:
        return "".join(map(lambda character: character if character.isalnum() else " ", text.lower())).split()

    def fedos_mak_count_word_frequencies(words: list[str]) -> dict[str, int]:
        return dict(map(lambda word: (word, words.count(word)), dict.fromkeys(words)))

    def fedos_mak_top_word(freq: dict[str, int]) -> "str | None":
        return None if not freq else min(freq, key=lambda word: (-freq[word], word))

    print("Слова:", fedos_mak_split_words("Привет, мир! Привет... ФП — это полезно."))
    print("Частоты:", fedos_mak_count_word_frequencies(fedos_mak_split_words("Привет, мир! Привет... ФП — это полезно.")))
    print("Самое частое слово:", fedos_mak_top_word(fedos_mak_count_word_frequencies(fedos_mak_split_words("Привет, мир! Привет... ФП — это полезно."))))

## Алгоритм разбиения текста

Метод lower приводит все символы к нижнему регистру. map проверяет каждый
символ методом isalnum. Буква или цифра сохраняется, любой разделитель и знак
препинания заменяется пробелом. Метод join собирает преобразованную строку, а
split разделяет её по пробельным символам и возвращает список непустых слов.

Замена знака препинания пробелом важна: слова по разные стороны знака не
склеиваются. Например, строка **мир,труд** превращается в два слова
**мир** и **труд**.

## Алгоритм подсчёта частот

Выражение dict.fromkeys сохраняет по одному экземпляру каждого слова в порядке
первого появления. Затем map создаёт для каждого уникального слова пару из
самого слова и результата words.count(word). Конструктор dict формирует
итоговый словарь.

Исходный список не сортируется, не дополняется и не изменяется.

## Алгоритм поиска самого частого слова

Для пустого словаря условное выражение возвращает None. Для непустого словаря
min получает ключ сравнения в виде пары:

    (-freq[word], word)

Отрицательная частота ставит более частые слова раньше. Второй элемент пары
задаёт алфавитный выбор при равенстве частот.

## Проверка чистоты

| Критерий | Выполнение |
|---|---|
| Детерминированность | Одинаковые аргументы дают одинаковые результаты |
| Тотальность | Выполняется на описанных областях определения |
| Ввод и вывод | Внутри трёх функций отсутствует |
| Импорт модулей | Отсутствует |
| Глобальное изменяемое состояние | Не используется |
| Мутация аргументов | Отсутствует |
| Промежуточные присваивания | Внутри вычислений отсутствуют |

Три публичные функции объявлены через def с аннотациями входных и выходных
типов. Тело каждой функции сразу возвращает выражение и не создаёт
промежуточных переменных.

## Рефлексия по уровню 4

### Есть ли в функциях побочные эффекты

Нет. Функции не печатают данные, не читают файлы, не импортируют модули, не
используют внешнее изменяемое состояние и не изменяют аргументы.

Внизу файла расположены отдельные вызовы print для демонстрации результата.
Вывод на экран является побочным эффектом этих строк, но не самих трёх функций.

### Можно ли назвать функции детерминированными

Да. Результат каждой функции определяется только значением её аргумента.
Для слов с одинаковой частотой действует постоянное алфавитное правило.

### Что произойдёт при пустой входной строке

**fedos_mak_split_words("")** вернёт пустой список. Передача этого списка в
**fedos_mak_count_word_frequencies** даст пустой словарь. Передача пустого
словаря в **fedos_mak_top_word** даст None.

## Контрольный пример

Исходный текст:

    Привет, мир! Привет... ФП — это полезно.

Список слов:

    ["привет", "мир", "привет", "фп", "это", "полезно"]

Словарь частот:

    {
        "привет": 2,
        "мир": 1,
        "фп": 1,
        "это": 1,
        "полезно": 1
    }

Самое частое слово:

    привет

## Контрольные проверки

| Проверка | Ожидаемый результат |
|---|---|
| Приведение к нижнему регистру | Все слова записаны строчными буквами |
| Запятые, точки, тире и скобки | Не входят в слова |
| Подсчёт слова привет | 2 |
| Самое частое слово | привет |
| Пустой текст | Пустой список |
| Частоты пустого списка | Пустой словарь |
| Лучшее слово пустого словаря | None |
| Два слова с одинаковой частотой | Первое по алфавиту |
| Исходные список и словарь | Не изменяются |

## Вопросы для защиты

### Почему функции являются чистыми

Они зависят только от аргументов, не выполняют ввод или вывод и не изменяют
переданные данные.

### Как удаляются знаки препинания

map проверяет каждый символ методом isalnum. Символ, который не является
буквой или цифрой, заменяется пробелом. Затем join собирает строку, а split
выделяет слова по пробельным символам.

### Почему нельзя просто удалить знак препинания

При полном удалении из строки **мир,труд** получилось бы слово **миртруд**.
Замена пробелом сохраняет границу между словами.

### Почему исходный список не мутирует

Методы count и fromkeys только читают элементы списка. map и dict создают
новый словарь.

### Почему результат top_word однозначен

Сначала слова сравниваются по убыванию частоты, затем по алфавиту. Поэтому
равенство частот не делает результат неопределённым.

### Какова вычислительная сложность

Разбиение текста имеет линейную сложность относительно длины строки. Подсчёт
частот в данной учебной реализации использует count для каждого уникального
слова, поэтому в худшем случае имеет квадратичную сложность O(n²). Поиск самого
частого слова имеет линейную сложность O(k), где k — число уникальных слов.

## Вывод

В работе реализованы три чистые функции с аннотациями типов. Они разбивают
текст на слова, подсчитывают частоты и находят самое частое слово. Решение
использует lambda внутри функций высшего порядка и не использует import,
ввод-вывод, мутацию аргументов и промежуточные присваивания. Для пустого текста
полный конвейер возвращает пустой список, пустой словарь и None.
